# UV275 Chlorine Dose Prediction

Software source code accompanying the manuscript **Real-Time Chlorine Dose Prediction for Drinking Water Disinfection Using UV275 Absorbance: Modeling, Validation, and Device Implementation**.

This repository contains the Python application, GUI modules, configuration files, model coefficients, demo-data scripts, dependency list, and application packaging specifications supplied by the authors. The source files are published as provided.

Python dependencies are listed in `requirements.txt`. Application entry points are provided in `main.py`, `waterplant_reader.py`, and `start_guard.py`. Instrument operation requires the corresponding local hardware and configuration.

Local virtual environments, Python caches, runtime logs, operational databases, backups, and archived outputs are excluded from this source-code repository.
